The AI Workplace Productivity Assistant is a modern, responsive web application built to help professionals automate everyday workplace tasks using artificial intelligence. Designed as a single integrated SaaS-style dashboard, the app brings together several AI-powered tools behind one clean, consistent interface. Rather than forcing users to jump between different platforms or services, everything they need lives in one place, making it ideal for real workplace environments where efficiency and clarity matter. The overall goal is simple: reduce the friction of routine tasks like writing emails, planning work, and researching topics, so users can focus on higher-value work.

The application currently implements three core features. The Smart Email Generator allows users to create professional emails from a short description of intent, with tone options including Formal, Friendly, and Persuasive, plus length control for short, standard, or detailed messages. The AI Task Planner builds daily or weekly schedules from a list of tasks and goals, prioritises work, suggests time blocking, and highlights risks or overload. The AI Research Assistant offers two modes: Summarize, which condenses pasted articles or notes into key points, and Explore, which researches a topic and returns insights, action points, and practical recommendations. Across all features, AI-generated responses appear in editable text areas that can be revised, copied to the clipboard, or cleared and regenerated. A responsible AI disclaimer is also reused throughout the app, reminding users that AI output should be reviewed before use and may contain inaccuracies.

The project is built on a modern full-stack web stack. It uses React 19 with TanStack Start for server-side rendering capabilities, TanStack Router for file-based routing, and Vite 7 as the build tool. TypeScript provides type safety, while Tailwind CSS v4 handles styling through semantic theme tokens defined in the global styles file. The user interface relies on shadcn/ui and Radix UI primitives, with lucide-react for icons and sonner for toast notifications. Typography uses Sora for display headings and Manrope for body text. Server logic is written with TanStack createServerFn, and AI responses are streamed through the Lovable AI Gateway. Bun is the package manager, and the app is deployed on Lovable's edge hosting.

Setting up the project locally is straightforward. First, clone the repository and install dependencies using bun install or npm install. Next, create a .env file in the project root and add a LOVABLE_API_KEY, which is read server-side only inside the server function. To start development, run bun run dev or npm run dev, which serves the app at http://localhost:8080. For production, run bun run build followed by bun run preview. Because the key stays on the server, it is never exposed to the browser, keeping the integration secure.
